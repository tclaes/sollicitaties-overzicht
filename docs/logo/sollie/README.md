# Sollie — logo en gebruiksgids

**Idee:** alle vacatures gaan door de zeef; één stip blijft over: de match. De accentstip in het
raster keert terug als i-punt in het woordmerk.

## Bestanden

| Bestand | Gebruik |
|---|---|
| `sollie-horizontal.svg` | Standaard logo (header, README, e-mail) |
| `sollie-stacked.svg` | Vierkant gebruik (loginpagina, posters) |
| `sollie-symbol.svg` | Alleen symbool, vanaf 32 px |
| `sollie-symbol-small.svg` | Vereenvoudigd 2×2-symbool voor 16–32 px (favicon) |
| `sollie-wordmark.svg` | Alleen woordmerk |
| `*-dark.svg` | Variant voor donkere achtergronden (lichte inkt, lichter violet) |
| `varianten/` | Zwart, wit, violet en vierkant (SVG + PNG) |
| `web/` | `favicon.svg` (past zich aan donker/licht aan), `favicon.ico`, apple-touch-icon, PWA-iconen, `head-snippet.html` |
| `presentatie.html` | Presentatiebord met toepassingen. De tekst en naam in de mockups zijn plaatshouders |

Alle SVG's zijn gevulde paden zonder tekst of rasters: de letters zijn getekend als outlines.

## Kleuren

| Rol | Licht | Donker | Contrast |
|---|---|---|---|
| Inkt | `#14141f` | `#f5f5f3` | n.v.t. |
| Accent (de match) | `#0e9aa7` (teal) | `#3cc4d0` | 3,4:1 op wit; 8,7:1 op `#14141f` |

Het accent is bedoeld voor grafische vlakken (de stippen), niet voor lopende tekst: op wit haalt teal
3,4:1, genoeg voor een grafisch element (3:1) maar niet voor tekst (4,5:1).
Eén kleur (zwart/wit) werkt: de match blijft herkenbaar doordat de stip groter is.

## Regels

- **Vrije ruimte:** minimaal de diameter van de accentstip (ongeveer ⅓ van de symboolhoogte) rondom het logo.
- **Minimale grootte:** horizontaal logo 96 px breed; symbool 32 px; onder 32 px het 2×2-symbool gebruiken.
- **Niet doen:** stippen verplaatsen of aantal wijzigen, accentstip van kleur wisselen buiten het palet,
  woordmerk in een ander lettertype zetten, effecten (schaduw, verloop) toevoegen.
- **Donkere achtergrond:** altijd het `-dark`-bestand gebruiken in plaats van het donkere logo te laten staan.

## Beperkingen

- Geen merkenonderzoek gedaan; controleer de naam "Sollie" en het logo zelf bij een merkenregister
  voordat je het buiten dit persoonlijke project gebruikt.
- Het woordmerk is handmatig geconstrueerd (monoline, geen font) en alleen gecontroleerd op de letters
  in "Sollie".
